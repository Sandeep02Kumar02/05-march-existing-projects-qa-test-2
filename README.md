# hao-backprop-test

Test project for backprop integration. **Do not touch!**

A minimal Python 3 Flask HTTP server that responds with "Hello, World!" to all requests at `127.0.0.1:3000`.

## Prerequisites

- Python 3.9+

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python app.py
```

The server starts on http://127.0.0.1:3000.

Alternatively, you can use the Flask CLI:

```bash
FLASK_APP=app.py flask run --host=127.0.0.1 --port=3000
```
